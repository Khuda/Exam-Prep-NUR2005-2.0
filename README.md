# NUR2005 Exam Prep

A static, client-side revision website for NUR2005 Applied Pathophysiology and Pharmacology. It includes topic notes, MCQs, short-answer prompts, multi-step medication calculations, a timed mock exam, and local progress tracking.

## Run locally

```bash
python3 -m http.server 3000
```

Open `http://localhost:3000`.

## GitHub Pages

This site has no server or database dependency. Publish the repository with GitHub Pages using the repository's Pages settings and choose the `main` branch root as the source. Progress is stored in each learner's browser using `localStorage`.
